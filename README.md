# Hi, you beautiful human being 👋

My name is Janne, and I'm honored to see you here. I'm a web designer and developer from Finland, so I'm not much of a contributor here on GitHub. Still, it's more than cool that places like this exist.

I work for myself, in a company called [Janne Parri Oy](https://www.janneparri.com/). Yeah, I know, quite an original name. Since 2020 I've built design-led websites and design systems for marketing teams, from start to finish, in [Webflow](https://webflow.com/@janneparri) or [Astro](https://astro.build/). I also host [Webflow and Friends](https://www.janneparri.com/webflow-and-friends), a podcast about building websites with Webflow and the tools around it.

You might be a hardcore developer, and in that case I salute you! I've scratched the surface of a few languages, but what really gets me going is everything you get to build with them. I'm saying this to thank you. Around here I might be the "noob", but this noob is way better off for all the help I've gotten.
